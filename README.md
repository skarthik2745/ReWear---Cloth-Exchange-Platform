# ♻️ ReWear – Sustainable Clothing Exchange

**Give More. Waste Less. ReWear Today.**

ReWear is a community-driven platform that enables people to **donate and exchange gently used clothes**, reducing textile waste while supporting people in need.

## 🚀 Features

* 👤 Donor and Receiver registration
* 👕 Upload and browse clothing items
* 📩 Donation request management
* ⭐ Points and reward badges
* 🏆 Community leaderboard
* 🤝 NGO donation event listings
* 🔐 Secure Firebase authentication

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Database:** Firebase Realtime Database
* **Authentication:** Firebase Authentication
* **Version Control:** GitHub
* **Deployment:** Netlify

## 🎯 Objective

* Reduce clothing and textile waste
* Promote sustainable fashion
* Encourage clothing reuse and donation
* Connect donors with people in need
* Support a circular economy

## 🏆 Highlights

* Built a functional web-based prototype
* Implemented real-time Firebase data management
* Added gamification through points, badges, and leaderboard
* Deployed the platform online
